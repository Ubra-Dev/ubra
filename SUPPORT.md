# Getting help with Ubra

- Ask usage and setup questions in
  [GitHub Discussions](https://github.com/stackwares/ubra-tauri/discussions).
- Report reproducible bugs using the
  [bug report template](https://github.com/stackwares/ubra-tauri/issues/new?template=bug_report.yml).
- Suggest improvements using the
  [feature request template](https://github.com/stackwares/ubra-tauri/issues/new?template=feature_request.yml).
- Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
- Report community conduct concerns by email to `nemoryoliver@gmail.com`.

Search existing reports first. Include the Ubra version, operating system, minimal
steps, and expected/actual behavior. Redact credentials, private paths, terminal
content, and agent conversations before sharing logs or screenshots.

Ubra is maintained on a best-effort basis. There is no guaranteed response time
for general support or feature requests. Security reports have the initial
response target documented in SECURITY.md. Sponsorship is not a support contract.

For patches and development setup, see [CONTRIBUTING.md](CONTRIBUTING.md).
