# Ubra governance

Oliver Martinez ([@oliverbytes](https://github.com/oliverbytes)) is the current
maintainer and makes final decisions about scope, changes, and releases.

Anyone may report problems, propose improvements, or submit a pull request.
Discuss substantial changes in an issue before implementing them. Decisions are
recorded in the relevant issue or pull request, with reasons when a proposal is
declined. The README roadmap communicates priorities, not delivery commitments.

Changes normally go through pull requests and required CI checks. The maintainer
reviews correctness, compatibility, security, and maintenance cost before merging.
Release tags require CI, signed platform bundles where applicable, and native
verification on macOS, Linux, and Windows. See [the release guide](docs/RELEASING.md).

Contributors retain copyright in their work and submit it under MIT. Sponsorship
does not grant special decision rights or change the license. Requests from
sponsors are evaluated through the same public process as other requests.

Additional maintainers may be invited based on sustained contributions, review
quality, and community participation. Changes to maintainership or governance will
be announced in the repository. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for
community standards and [SPONSORSHIP.md](SPONSORSHIP.md) for funding expectations.
